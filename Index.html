File Index.html untuk integrasi Google Apps Script & Google Spreadsheet

1. Penempatan di Google Apps Script

File ini dipasangkan bersama file Code.gs pada editor Google Apps Script dengan memilih menu File > Baru > File HTML dan memberi nama Index.

2. Koneksi Otomatis Database

Fungsi google.script.run atau API endpoint doGet(e) dan doPost(e) di Code.gs otomatis membuat 9 sheet tabel database di Google Spreadsheet Anda.

3. Aplikasi Lengkap SiApgus

Aplikasi lengkap dengan interaksi realtime, login Admin & Guru, Jurnal, Nilai KKTP, Absensi, Cetak Rapor, dan Export/Import XLSX berjalan penuh pada antarmuka SiApgus terpadu.

Untuk menjalankan seluruh fitur lengkap dengan antarmuka modern yang responsif, gunakan aplikasi utama SiApgus.
